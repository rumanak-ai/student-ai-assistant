# Smart AI Chatbot

A rule-based chatbot developed using Python that can interact with users through pattern matching and provide responses to common questions and commands.
## 📌 About the Project

Smart AI Chatbot is a Python-based rule-driven conversational program.

The chatbot uses regular expressions and predefined rules to identify user input and generate suitable responses. It also includes features such as basic mathematical calculations, AI-related information, date and time display, jokes, study tips, motivation, chat history, and conversation statistics.

This project was developed to practice Python programming concepts such as classes, dictionaries, functions, loops, regular expressions, file handling, and JSON.
## ✨ Features

- 👋 Interactive greetings
- 🤖 AI-related questions and answers
- 🧠 Machine Learning information
- 🔬 Deep Learning information
- 🐍 Python information
- 🧮 Basic mathematical calculations
- 😂 Random programming jokes
- 💡 Motivational messages
- 📚 Study tips
- 💻 Programming facts
- 🕐 Current date and time
- 📖 Chat history storage
- 📊 Conversation statistics
- ❓ Help menu
- 👤 Personalized responses using the user's name
